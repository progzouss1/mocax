Mocax constructor.

Builds a Mocax object, taking a callable function, the number of dimensions, a domain, and the accuracy parameters and/or an error threshold, and other optional parameters.

Parameters
[in]originalThe original, callable function. If a None function and only n are passed, construction will be incomplete and must be finished with get_evaluation_points() and set_original_function_values(). Allowed types: Callables, None
[in]num_dimensionsThe number of dimensions for this function. An integer number in the range [1,58]. Allowed types: int, long
[in]domainA MocaxDomain object with the domain of the function to construct. Allowed types: mocaxpy.MocaxDomain.MocaxDomain
[in]error_thresholdError threshold for the first dimension (if n is not None) or every dimension (if n is None). Satisfies that errorThreshold > 0.0. Can be None if n isn't. Allowed types: float
[in]nA MocaxNs object with the accuracy parameter(s) of each dimension (if errorThreshold is None) or all but the first dimensions (if errorThreshold is not None). Can be None if errorThreshold isn't. Allowed types: mocaxpy.MocaxNs.MocaxNs
[in]special_pointsAn optional MocaxSpecialPoints object with a set of special points. Allowed types: mocaxpy.MocaxSpecialPoints.MocaxSpecialPoints, None
[in]max_derivative_orderAn optional maximum derivative order of this function. An integer number in the range [0,MOCAX_DERORDER_MAX]. Allowed types: int, None
[in]additional_dataAn optional parameter with optional data that will be forwarded to the original function during the construction. Allowed types: c_void_p, None

◆ get_constructor_type()

def mocaxpy.Mocax.Mocax.get_constructor_type (   self)

Gets the kind of construction used to build the function.

Returns
One of the following values (Return type: int):
  • 0 – The constructor used an accuracy parameter N for each dimension.
  • 1 – The constructor used an error threshold for the first dimension, and an accuracy parameter N for each of the remaining dimensions.
  • 2 – The constructor used a single error threshold for every dimension.
