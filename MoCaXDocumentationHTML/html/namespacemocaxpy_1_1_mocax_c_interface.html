◆ MOCAX_ORIGINAL_FUNCTION_DEF

mocaxpy.MocaxCInterface.MOCAX_ORIGINAL_FUNCTION_DEF = CFUNCTYPE(c_double, POINTER(c_double), c_void_p)

The form of a valid function callback.

MoCaX will expect a function callback that:

  • Takes two parameters:
    1. A C array of double-precision floating point input values.
    2. A C pointer to any additional/context data (None can be used when no additional data is required).
  • Returns a double-precision floating point result.
